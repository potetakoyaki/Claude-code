# タスクフレンド

Claude Codeと一緒に考えた副業アイデアやタスクを、後回しにしてしまわないように、
友達のようなチャットボットが定期的に声をかけてくれるタスク管理アプリです。

一般的なタスク管理アプリの「管理されてる感」が苦手な人向けに、チャット形式で
タスクを登録し、忘れた頃に自然な言葉でリマインドしてくれる体験を目指しています。

## できること

- チャットにタスクを打ち込むだけで登録
- 期限はチップをタップするだけで設定(今日中 / 3日以内 / 1週間以内 / 日付指定 / なし)
- アプリを開いている間、設定した頻度でボットが放置タスクを気にかけて声をかけてくれる
- 放置期間や期限の近さに応じてセリフのトーンが変化(やさしめ→ちょっと本気)
- タブを見ていない間はブラウザ通知でこっそりお知らせ(通知を許可した場合)
- 「やった!」「あとで」「もうやらない」をワンタップで返信
- タスク一覧シートで完了・スヌーズ・削除もまとめて確認可能

## 開発

```bash
npm install
npm run dev     # http://localhost:3000/Claude-code/
npm run build
```

## 制限事項

通知やリマインドは、ブラウザでこのページが開かれている間(バックグラウンドタブでも可)
動作する仕組みです。ブラウザ自体を完全に閉じている間はリマインドされません。
