# やること — タスク管理アプリ

考えるだけで終わらせず「実行」に移すための、通知付きシンプルなタスク管理アプリです。
**インストールやビルドは不要**。ブラウザで開くだけで動きます。

## できること

- ✅ タスクの追加・完了・編集・削除
- ⏰ 期限の設定と並び替え（おすすめ順／期限順／優先度順／追加順）
- 🔴 優先度（高・中・低）とカテゴリ／タグでの分類・絞り込み
- ☑️ サブタスクとメモ
- 🔔 期限が来たタスクの通知
- 🧠 ブレインダンプ：走り書きを端末内で解析し、期限・優先度・カテゴリ付きで自動タスク化（API不要・無料）
- 📨 共有から取り込み：他アプリ（Claudeアプリなど）の文章を「共有 → やること」でそのままタスク化（Android）
- 🎯 「今日」タブと「次にやる1件」で、まず一歩を後押し
- 💾 データは端末のブラウザ内に保存（サーバー送信なし）。バックアップの書き出し／読み込みも可能

## 使い方A：Androidアプリとして端末内で使う（おすすめ・通知が確実に届く）

サーバー不要・端末内で完結する **Androidアプリ（APK）** を自動ビルドします。
アプリを閉じていても、期限が来ると **OSのローカル通知** で確実にお知らせします。

1. このリポジトリの **Actions → Build Android APK** が成功すると、
   **Releases** の「やること Android APK（最新）」に `yarukoto.apk` が添付されます。
2. **Androidのブラウザで `yarukoto.apk` をタップ** してダウンロード→インストール。
   - 初回は「不明なアプリのインストール」を許可する必要があります。
3. アプリを開いたら **通知を許可** してください。これで期限通知が届きます。

> このAPKはデバッグ署名のため、個人利用向けです。Google Play 配布には別途署名が必要です。

## 使い方B：ブラウザ／PWAで使う

### 1. スマホ・PCのブラウザで開く
GitHub Pages で公開する設定にしてあります。リポジトリの **Settings → Pages → Build and deployment → Source を「GitHub Actions」** に設定すると、`main` ブランチへのマージ後に下記URLで公開されます。

```
https://potetakoyaki.github.io/Claude-code/
```

スマホで開いたら、ブラウザの共有メニューから **「ホーム画面に追加」** すると、普通のアプリのように使えて通知も受け取れます（iPhoneは iOS 16.4 以降、ホーム画面に追加したうえで通知を許可してください）。

### 2. ローカルで試す（PC）
`www` フォルダを簡易サーバーで開きます（通知・オフライン機能を試すにはサーバー経由が必要です）。

```bash
cd www && python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 通知の違い（重要）

- **Androidアプリ（使い方A）**: 期限時刻にOSのローカル通知を予約します。**アプリを閉じていても通知が届きます。** サーバー不要・端末内で完結します。
- **ブラウザ／PWA（使い方B）**: 通知は **アプリ（タブ／ホーム画面アプリ）を開いている間** に届きます。完全に閉じた状態での通知はWebの仕様上できません。確実に通知してほしい場合は使い方Aを選んでください。

## データの保存場所

すべて使っている端末内（localStorage）に保存され、外部には送信されません。
機種変更や別端末への移行は、メニュー（右上「⋯」）の **バックアップを書き出す／読み込む** で行えます。

## 構成（開発者向け）

- `www/` … アプリ本体（素のHTML/CSS/JS、ビルド不要）
- `capacitor.config.json` / `package.json` … Capacitor によるAndroidラップ設定
- `.github/workflows/android.yml` … APKを自動ビルドして Releases に添付
- `.github/workflows/deploy.yml` … `www` を GitHub Pages へ公開（`main`）
- `android/` は CI で生成するためコミットしません
